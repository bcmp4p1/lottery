Full Stack Engineer Test Task
Build a small MVP for an online lottery platform using Next.js, NestJS, and Supabase in an AI-driven
development environment.
The application should allow users to sign up, view available lottery draws, purchase tickets, and see their
purchased tickets. An admin should be able to create lottery draws, close a draw, and generate a random
winning number.
A draw should contain a title, description, ticket price, draw date, and status (Draft, Open, Closed, Finished).
Every purchased ticket must receive a unique ticket number within the draw.
Requirements

Use Supabase Auth for authentication.
Create a REST API with NestJS.
Store data in Supabase PostgreSQL.
Build a simple UI with Next.js and Tailwind CSS.
The development environment and workflow should be AI-driven (use AI tools during development
and be ready to explain how they were used).
Users should be able to:
View available draws
Purchase tickets
View their tickets
View winning numbers for completed draws
Admin should be able to:
Create draws
Close draws
Generate a random winning number for a draw

A link to the deployed application
A link to the GitHub repository
